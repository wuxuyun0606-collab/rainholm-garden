# 从下载到两只猫一起种地

需要 Node.js 20+，首次启动需要联网下载依赖。项目本身不要求模型 API Key，不会替你购买模型或托管服务。

1. 下载 [最新发行版](https://github.com/wuxuyun0606-collab/rainholm-garden/releases/latest) 的 Source code ZIP，解压。
2. 在项目目录运行 `node start.mjs`。macOS 可双击 `start.command`，Windows 可双击 `start.bat`；系统安全提示请按本机规则处理。
3. 浏览器自动打开连接页并登录。点「进入花园」，白猫就是你。
4. 回到「连接 AI」，选择客户端，照页面复制地址、AI 钥匙或 MCP 配置。详细步骤见 [AI 接入](AI_GUIDE.md)。
5. 对 AI 说：“先读花园状态和地图，看看我种了什么，再让黑猫说句话。”

停止：终端按 Ctrl+C。下次用同一目录启动，存档与钥匙会保留。

## 浏览器没有自动打开

打开 `http://127.0.0.1:5173/connect/`，运行 `node start.mjs --show-access` 查看玩家登录链接。这个命令会显示私人钥匙，只在自己的终端使用，不要发截图给别人。

端口被占用：`node start.mjs --port 5180`。查看钥匙时也带上同样参数。

## 手机接入

电脑运行 `node start.mjs --lan`，手机和电脑连接同一 Wi-Fi，打开终端列出的电脑地址。用 `node start.mjs --lan --show-access` 查看玩家登录链接。

Operit / Kelivo 的 MCP 地址同样用电脑 IP，例如 `http://192.168.1.20:5173/mcp`；手机上的 `localhost` 指手机自己。电脑需保持运行，防火墙需允许此端口。局域网 HTTP 不加密，只用于可信网络；远程访问使用 HTTPS。

## ChatGPT / Claude Chat

这两个产品的云端服务无法访问你的本机地址。可以先按 [Cloudflare 免费部署](CLOUDFLARE.md) 或 [其他部署方式](DEPLOY.md) 部署到公网 HTTPS，再连接。公网部署也必须带钥匙登录，不能把花园链接当成公开编辑权限。

## DeepSeek 官方聊天页

连接页选择 DeepSeek，复制快照给它。将它返回的单条 JSON 粘回页面，先预览，再点确认执行；把执行结果回给它。快照含游戏状态和最近说的话，不含钥匙。不要在聊天里粘贴玩家或 AI 钥匙。

需要自动执行时，在 Operit / Kelivo 中使用支持工具调用的 DeepSeek 模型，配置本项目 MCP。

## 常见情况

- **401 / 403**：检查是否把玩家钥匙与 AI 钥匙用反；网页登录用玩家钥匙，MCP / Actions 用 AI 钥匙。Claude 授权页例外：玩家钥匙用于你批准授权。
- **连接器不显示**：由客户端版本、套餐和账号权限决定，服务端不能开启产品权限。可使用便笺方式。
- **AI 说执行了，画面没变**：以工具返回结果为准。网页保持打开并切到指令对应场景；移动/气泡只保留最新一条待显示指令，种浇收已写入存档。
- **网页隔一会儿才更新**：游戏状态每 30 秒刷新，回到前台也会刷新。
- **重试扣了两次金币**：新接口需要沿用同一个 `requestId`。换编号代表新动作。最近 200 条结果保留用于重试；旧接口未指定编号不能保证重试去重。
- **忘记钥匙**：本机用 `--show-access`，Render 查看部署环境变量。不要删除整个数据目录，否则会丢存档；轮换方法见部署说明。
