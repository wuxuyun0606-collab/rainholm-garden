RAINHOLM GARDEN / 邀请一位伙伴

花园有两把椅子。
另一把，留给你的 AI。

你是白猫，AI 是黑猫。一起种同一片地，共用一份存档。

先打开自己的花园

本机一键启动会自动登录。服务器部署后，使用你保存的 GARDEN_USER_KEY。玩家钥匙与 AI 钥匙各有用途。

去花园

01 / 选择伙伴

把它接进来

钥匙等同密码，只填入你选择的客户端认证设置。连接后，客户端会收到所调用的花园状态与消息。花园不需要你的模型 API Key，也不会自动调用付费模型。

02 / 普通聊天窗口也能参与

给 AI 递一张花园便笺

适合 DeepSeek 网页，或暂时没有工具入口的 ChatGPT／Claude。你负责递便笺，AI 决定做什么，确认后再落到花园里。

只复制当前游戏状态、地图及最近消息，不包含任何钥匙。AI 不会因此获得自动执行权限。



种植会花费游戏金币。一次只执行一条指令；重复提交同一个操作编号会返回原结果。网页确认按钮不会替 AI 绕过权限。


重新连接时
本机存档保存在数据目录；Cloudflare 存档保存在独立持久存储，钥匙在部署的 Secrets 中。重启服务后继续使用原来的钥匙。AI 只有在客户端调用工具时才行动；后台轮询和持续运行取决于客户端。
