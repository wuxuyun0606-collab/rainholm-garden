# 小白小黑四向走路 · PNG 试装稿 v1

两只猫 × 正/背/左/右四向 × 每向 8 帧，共 64 张 256×256 RGBA PNG。各方向另有 2048×256 横条。按 manifest.json 取文件，0001 到 0008 循环，建议每帧 110 ms，一轮 880 ms。正面 front 朝屏幕下方，back 朝上，left/right 分别朝屏幕左右。

每帧脚底不透明像素最下行为 y=231，脚底挂点用 (128,232)，比例锚点为 (0.5,0.90625)。头部中心线经平移对齐到 x≈128。同方向只用共享缩放，没有逐帧拉伸；左右侧面分别生成。动画位移仍交给现有导航，不叠加整只上下颠簸。停止时请停止播帧，避免原地蹬腿。

这是新绘制的光栅四向动画，不是 motion3，也没有修改 moc3、Live2D 贴图或生产走路代码。接线需要四向 Sprite 渲染显示；同一个角色只能显示一份。不要同时显示 Live2D 身体与帧图。先在副本试装转向、停走和现役尺寸；如何接回待机须与当前控制层明确，不能把本包当现有 Live2D 参数补丁直接覆盖。

白猫保留奶油白毛、可可眼、ω嘴和淡粉腮红；黑猫保留实心暖黄放空眼、∧嘴，腮红稍提亮提粉。背面不画脸。三组原稿的尾巴换边已局部返修。

本包为审稿/试装，不代表已在花园安装。GIF 仅便捷预览，透明 PNG 为交付原件；MP4 同时展示大图和 80 px 图盒（猫本体约 64 px），不是生产实录。

检查：64 帧非空、未碰边；裁切/缩放无夹断；脚底统一；清除了洋红底边缘溢色。逐方向尺寸波动和裁切报告见 QC.json。动态美术仍须在人实际操控的转向场景下终审。

制作：内置 image_gen + generate2dsprite 本地去底/拆帧/缩放/对齐。工具未提供确切模型名称，不能核实或宣称是 image2/2.5。完整提示词在 prompts.json，保留此事实供型号要求复核。
